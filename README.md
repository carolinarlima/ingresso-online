# 🎫 Ingresso Online: Sistema de Vendas e Estoque

> **Status do Projeto:** Concluído ✅

O **Ingresso Online** é uma aplicação interativa que simula a compra de ingressos para eventos. O sistema gerencia a disponibilidade de três setores distintos (Pista, Cadeira Superior e Cadeira Inferior), realizando a subtração automática do estoque e validando a quantidade solicitada pelo usuário.

## 🚀 Funcionalidades Principais

* **Seleção de Setores:** Dropdown para escolha entre Pista, Cadeira Superior e Cadeira Inferior.
* **Cálculo de Subtração:** Atualização dinâmica da quantidade disponível após cada compra bem-sucedida.
* **Validação de Quantidade:** Sistema que impede a compra caso a quantidade solicitada seja maior que o estoque disponível.
* **Feedback Instantâneo:** Alertas visuais que informam ao usuário o sucesso da compra ou a falta de ingressos.
* **Reset de Fluxo:** Interface que permite múltiplas compras consecutivas até o esgotamento total dos setores.

## 🧠 Aprendizados Técnicos

Durante o desenvolvimento deste projeto, foquei em:
1.  **Manipulação Dinâmica de Texto:** Uso de `textContent` para atualizar os valores de estoque exibidos na tela sem recarregar a página.
2.  **Lógica Condicional:** Implementação de verificações (`if/else`) para garantir a integridade do estoque.
3.  **Conversão de Tipos:** Prática constante de conversão de strings do HTML para números inteiros (`parseInt`) para cálculos precisos.
